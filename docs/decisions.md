# 技術選擇紀錄

## 為什麼用 Tauri + React
- 要做成 macOS 桌面程式，之後要能出 Windows 版。Tauri 兩邊都支援，安裝檔小（Electron 動輒上百 MB）。
- 畫面用 React，拉桿與圖表的生態成熟；計算與畫面分開，核心邏輯換殼也能用。

## 資料存放
- 全部在本機。自動存在瀏覽層的 localStorage；另可存成 JSON 檔、再讀回。
- 檔案格式：`{ app, version, savedAt, scenario }`，讀入時缺少的欄位用預設值補。

## 匯率
- 來源 TradingView（TWDUSD、BTCUSD）。網頁數字是載入後才畫出，直接抓網頁抓不到，改問它的查價介面。
- 經 Tauri 的 http 外掛發出請求（避開瀏覽器跨網域限制），權限只開 `scanner.tradingview.com`。
- 抓不到時可手動填寫。

## 範圍
- 暫不含「利率參考」「評估建議」。
- 房價拉桿 500 萬–1 億；利率 1%–10%。

## 拉桿底色
- 把拉桿從最小拉到最大取 100 個點，每點整份重算一次，依結果上色。拖動時才不用猜哪裡買不起。
