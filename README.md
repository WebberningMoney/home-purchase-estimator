# 換屋試算

賣掉現在的房子、買一間新的，錢夠不夠？拉動房價和利率，馬上知道買不買得起，也看得到存款每個月怎麼變。

資料只存在你的電腦，不會上傳。

## 怎麼用

1. 左邊拉「房價」「利率」「貸款成數」。拉桿底色就是答案：綠＝買得起、藍＝靠存款撐得住、黃＝勉強、紅＝買不起。
2. 右邊看結論、現金推移圖和重點數字。
3. 想細調就展開「家庭收支」「資產」「現有貸款」「賣舊屋」。每個數字都可以直接打字。
4. 「儲存檔案」存成檔案，「開啟檔案」再讀回來。平常改動也會自動記住。

範例數字是虛構的，請換成自己的。

## 安裝與執行

需要 Node.js 20 以上，以及 Rust（<https://rustup.rs>）。

```
npm install
npm run tauri dev      # 開發，會跳出視窗
npm run tauri build    # 打包成 Mac 程式
npm test               # 跑測試
```

只想看網頁版：`npm run dev`，開 <http://localhost:1420>。

## 匯率

「資產」裡的「用 TradingView 更新」會抓台幣兌美元與比特幣價格。抓不到就手動填。
